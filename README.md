# Soutien-la-d-tresse-psychologique-Ile-de-la-R-union-SDPIR-
 (SDPIR) se fonde sur la conviction que la santé mentale est un droit fondamental, indissociable de la dignité sociale. Dans un contexte local marqué par une précarité accrue, nous défendons un accompagnement qui ne se limite pas à la consultation, mais qui s'ancre dans la réalité quotidienne du bénéficiaire.
